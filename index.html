How to run & refresh this data

What this is. This tab shows a LinkedIn analysis of 16 competitor cybersecurity companies, the topics they post about, how much engagement they get, and their standout posts. The analysis is built by Claude Code (the AI assistant) and saved in a folder on your Desktop called the linkedin competitor analysis vault. This page just shows a copy of it. To update what you see, do these three steps in order.

  1. Get fresh data use Source Harvester Open Source Harvester (in Tools on the home screen), switch to the LinkedIn Presence tab, paste the competitors' LinkedIn links (one per line), and click Copy for Claude Code. Then paste what it copied into Claude Code's chat and press Enter. Claude reads each company's recent posts and rebuilds the analysis on its own. The first time, it may ask you to add an "Apify" key, just follow what it says.
  2. Add the written summary (optional) do this in Claude Code The charts and numbers update by themselves. If you also want the written "Analyst read" commentary at the top refreshed, just ask Claude in the same chat: Write the analyst notes for the latest linkedin-presence run.
  3. Show it here do this in Claude Code Still in Claude Code, type this and press Enter. Claude runs it for you - no need to open a separate Terminal app: Refresh the competitor intelligence data (run refresh-competitor-data.sh). When it says it's done, reload this page (Cmd + R). The "Latest run" date at the top of the tab will change to the new date, that's how you know it worked.

Not sure if the data is current? Check the "Latest run" date near the top of this tab. If it looks old, run the three steps above.
