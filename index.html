    How Signal works

    Signal is Stern's cybersecurity content assistant, and these eleven tools are what it has at its disposal. One workflow runs through all of them. Here's the shape of it, and which tool to reach for at each step. Click anything to open it.

    The loop

    Every tool works the same way, so you only have to learn this once. The launcher writes the request; your Claude Project does the work. You move between the two.

    1. 1Pick the tool for where you are
    2. 2Fill in the fields
    3. 3Copy the request
    4. 4Paste it into your Claude Project
    5. 5Read what comes back
    6. 6Move to the next tool

    ↻ Then repeat, until the post is ready to publish.

    Start with a buying moment

    Nearly every tool asks you to pick a buying moment first. A moment is the point where a security buyer stops browsing and starts looking, the thing that just happened to them. Writing to one means the post lands on somebody with a reason to care. These eight are Stern's.

    The workflow

    Left to right is the life of one post. You don't always start at the far left, so tell it what you've already got and it'll light the path.

    Running behind the scenes

    These keep the engine fed. Most are run by the admin in Claude Code, not by the marketing team, so if one asks for a terminal that's expected rather than broken.

    Visual Designer

    Build a visual brief for a post: layout, copy, and brand direction a designer or Canva can execute. Brief only: no image is generated here.

    Vertical 9:16 fills a phone screen, which is what you want for video. LinkedIn shows feed images no taller than 4:5, so a 9:16 still gets cropped in the feed, the brief says so when you pick it.

    The brief will spell out the text for each slide in order.

    How you'll generate these slides

    1. The brief comes back with a master prompt plus one prompt per slide, and the same steps written out in full.
    2. Open one image generator conversation and keep every slide in it, so the look carries from slide to slide.
    3. Paste the master prompt on its own first. Check slide 1 and fix the master before going on, since every later slide inherits it.
    4. Then paste the slide prompts one at a time, in order, waiting for each image. If a slide drifts, paste the master again above it.
    5. Save as slide-01, slide-02… so the order survives the upload, then rebuild the text in Canva. Image models don't render exact copy or brand hex reliably.

    The background prompt is safe to ship after compositing in Canva. The concept prompt is for ideation only: an image model won't render your exact copy, colors, or logo, so it's a reference, not a final asset.

    How to run & refresh this data

    What this is. This tab shows a LinkedIn analysis of 16 competitor cybersecurity companies, the topics they post about, how much engagement they get, and their standout posts. The analysis is built by Claude Code (the AI assistant) and saved in a folder on your Desktop called the linkedin competitor analysis vault. This page just shows a copy of it. To update what you see, do these three steps in order.

    1. Get fresh data use Source Harvester Open Source Harvester (in Tools on the home screen), switch to the LinkedIn Presence tab, paste the competitors' LinkedIn links (one per line), and click Copy for Claude Code. Then paste what it copied into Claude Code's chat and press Enter. Claude reads each company's recent posts and rebuilds the analysis on its own. The first time, it may ask you to add an "Apify" key, just follow what it says.
    2. Add the written summary (optional) do this in Claude Code The charts and numbers update by themselves. If you also want the written "Analyst read" commentary at the top refreshed, just ask Claude in the same chat: Write the analyst notes for the latest linkedin-presence run.
    3. Show it here do this in Claude Code Still in Claude Code, type this and press Enter. Claude runs it for you - no need to open a separate Terminal app: Refresh the competitor intelligence data (run refresh-competitor-data.sh). When it says it's done, reload this page (Cmd + R). The "Latest run" date at the top of the tab will change to the new date, that's how you know it worked.

    Not sure if the data is current? Check the "Latest run" date near the top of this tab. If it looks old, run the three steps above.
